    Headlight - LH (SAE) (Remove and Replace)

    Correction code 1740010022 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

    Equipment:
    • 1133367-00-A Headlight Tester, Beissbarth, Model 815
    Parent topic: 1740 - Exterior Lights

    Torque Specifications

    Table 1. Torque Specifications: Headlight - LH (SAE) (Remove and Replace)
    Description Torque Value Recommended Tools Reuse/Replace Notes
    Bolts that attach the LH headlight to the body
    4 Nm (2.9 lbs-ft)
    • 10 mm socket
    		 Reuse

    Remove

    1. Remove the front fascia. See Fascia - Front (Remove and Install).
    2. Pull the locking tab to disconnect the electrical connector from the LH headlight.
    3. Remove the bolts (x2) that attach the LH headlight to the body, and then remove the LH headlight from the vehicle.
      Tip
      Use of the following tool(s) is recommended:
      • 10 mm socket
    4. Perform step 2 and 3 to the RH side headlight.

    Install

    1. Install the bolts (x2) that attach the LH headlight to the body.
      4 Nm (2.9 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      • 10 mm socket
    2. Connect the electrical connector to the LH headlight.
    3. Perform step 1 and 2 to the RH side headlight.
    4. Install the front fascia. See Fascia - Front (Remove and Install).
    5. Reinstall the firmware. See Software Reinstall - Touchscreen.
    6. Adjust the headlights. See Headlights - Adjust - Global (Wall Method) (Test/Adjust).
    7. Raise the LH front window and close the LH front door.
