# LightForge 2.0 evidence

This folder holds the new release gates and their inputs. The five files in `legacy-1.6/` are exact historical production worker dependencies, used to generate real old snapshots in migration tests. They are not bundled in the APK.

- `regression-verification.json`: current source hashes, Node regression and Python packaging results, and exact unchanged analysis asset verification.
- `browser-verification.json`: actual Chromium app, real workers/WebGL, simulated native bridge, UI edits, checksum-preserving Undo/Redo/reload, streamed exports before and after reload, and responsive captures.
- `native-verification.json`: production Java checks on the host JVM with Android stubs. Generated fixtures are local build outputs.
- `*-composer-verification.json`, `light-verification.json`, `movement-verification.json`: detailed current composer checks generated by the regression gate.

GitHub Actions retains logs and screenshots as workflow artifacts. The final packaging record at the repository root embeds the required gate results and verifies the actual update-compatible APK against current web assets. Generated timestamps and absolute runner paths are provenance, not a requirement to use a specific machine.

The six-song source reference set and the existing 1.6.0 model accuracy measurements remain in the original evidence folders. This release changes composition and editing; it does not claim a newly trained model, word transcription, perfect musical detection, or physical device/vehicle validation.
