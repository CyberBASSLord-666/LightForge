# 2.2 background execution evidence

Current release gates are regression-verification.json, browser-verification.json, native-verification.json, analysis-browser-verification.json, analysis-verification.json and android-background-verification.json. All are source-bound and mandatory. The Android gate is produced by the separate CI emulator job; host compilation is not substituted for an Android lifecycle result.

The [Chromium UI run](https://github.com/CyberBASSLord-666/LightForge/actions/runs/34123971705) covers 320, 393 and 768 px background controls and the full cockpit regression suite. Inspected captures show [progress at 320 px](background-progress-320.png), [cancellation recovery](background-recovery-320.png) and [device settings](background-settings-393.png). These screens use a simulated native status bridge; the Android lifecycle gate is independent.

The [Android lifecycle run](https://github.com/CyberBASSLord-666/LightForge/actions/runs/34127281784) passed on API 35 using the exact local APK payload with an isolated instrumentation signing identity. The test asserts actual Doze state, completes real Balanced inference and compilation after Activity destruction, reopens the saved result, cancels from the notification and checks that execution resources are released. It also invokes Android's media-processing timeout callback. The original release certificate is verified separately; no private signing credentials enter CI.

Run `npm test`, `node qa/release-2.2.0/browser.cjs`, `node qa/release-2.2.0/analysis-browser.cjs`, `python3 tests/verify_native_release.py --release 2.2.0` and `python3 tools/verify_retained_analysis.py --from-release 2.1.0`. Model dependencies, licensed reference excerpts and ephemeral CI instrumentation signing are documented in BUILD.md and the workflow. Numeric model evidence is strictly retained from unchanged 2.1 sources; Android background behavior has its own current execution test.

The [final main release-candidate workflow](https://github.com/CyberBASSLord-666/LightForge/actions/runs/34128499048) independently rebuilt the models and APK and passed the regressions, Chromium, native and Android lifecycle jobs. The current receipts below include that final execution.
